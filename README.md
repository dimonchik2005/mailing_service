# Mailing Service

Веб-приложение на Django для управления рассылками сообщений, получателями и статистикой отправки.

## Возможности

* регистрация с подтверждением email;
* вход, выход и восстановление пароля;
* управление получателями рассылок;
* управление сообщениями;
* создание, просмотр, редактирование и удаление рассылок;
* динамическое определение статуса рассылки;
* ручной запуск рассылки;
* отправка отдельного письма каждому получателю;
* сохранение истории успешных и неуспешных попыток;
* статистика отправленных сообщений;
* разграничение прав пользователей и менеджеров;
* блокировка пользователей;
* отключение рассылок;
* серверное кеширование через Redis;
* клиентское кеширование;
* автоматические тесты.

## Технологии

* Python 3.14
* Django 6
* PostgreSQL
* Redis
* Docker
* Poetry
* Bootstrap 5
* SMTP Mail.ru

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/dimonchik2005/mailing_service.git
cd mailing_service
```

Установите зависимости:

```bash
poetry install
```

Создайте файл `.env` на основе `.env.example` и заполните переменные окружения.

## PostgreSQL

Перед запуском создайте базу данных PostgreSQL и укажите параметры подключения в `.env`.

Примените миграции:

```bash
poetry run python manage.py migrate
```

## Redis

Запустите Docker Desktop.

При первом запуске создайте контейнер Redis:

```bash
docker run --name mailing-redis -p 6379:6379 -d redis:7-alpine
```

При последующих запусках:

```bash
docker start mailing-redis
```

Проверка:

```bash
docker exec -it mailing-redis redis-cli ping
```

Ожидаемый ответ:

```text
PONG
```

## Настройка почты

Для SMTP Mail.ru необходимо создать отдельный пароль для внешнего приложения и указать его в `.env`.

Обычный пароль от почтового ящика использовать не следует.

## Создание суперпользователя

```bash
poetry run python manage.py createsuperuser
```

## Настройка менеджеров

Создайте группу менеджеров и назначьте необходимые права:

```bash
poetry run python manage.py create_manager_group
```

После этого назначьте группу «Менеджеры» нужному пользователю через административную панель.

## Запуск проекта

```bash
poetry run python manage.py runserver
```

Приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

Административная панель:

```text
http://127.0.0.1:8000/admin/
```

## Роли

### Пользователь

* управляет своими получателями;
* управляет своими сообщениями;
* создаёт и запускает свои рассылки;
* просматривает собственную статистику.

### Менеджер

* просматривает все рассылки и получателей;
* просматривает список пользователей;
* блокирует пользователей;
* отключает рассылки;
* не редактирует и не удаляет чужие данные.

## Тестирование

Запуск всех тестов:

```bash
poetry run python manage.py test
```

Дополнительная проверка проекта:

```bash
poetry run python manage.py check
poetry run python manage.py makemigrations --check
```
